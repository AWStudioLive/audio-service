---

Высокопроизводительный асинхронный микросервис для распознавания речи и обработки голосовых команд в реальном времени с использованием **faster-whisper** (CTranslate2) и **WebSockets**. Предназначен для интеграции голосового ввода в расширение VS Code.

## 🚀 Возможности

- **Аппаратное ускорение:** Автоматическое определение CUDA GPU (NVIDIA) с фоллбэком на CPU.
- **Автонастройка CUDA под Windows:** Автоматическое добавление путей к DLL-библиотекам CUDA из pip-пакетов (`nvidia-cublas-cu12`, `nvidia-cudnn-cu12`).
- **Гибкие режимы обработки:** Поддержка сценариев `MANUAL`, `CONTINUOUS` и `BOUNDED`.
- **Распознавание триггеров:** Настраиваемые фразы активации, отправки и остановки с нормализацией пунктуации.
- **Протокол WebSocket:** Асинхронное взаимодействие на основе JSON-событий.
- **Контекстный словарь:** Подмешивание технических терминов для повышения точности распознавания программистской лексики.
